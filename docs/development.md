# Разработка MataSehat

[О проекте](../README.md)

Нативная утилита строки меню для macOS 26.5 и новее: мягкие напоминания о моргании во время работы.

- Два вида напоминаний: «Глаз» и «Затемнение».
- Интервал 3, 4, 5, 10, 20 или 30 секунд; при первой установке — 5 секунд.
- У глаза девять положений: центр, середины четырёх краёв и четыре угла. Размер 50–200% от прежнего центрального глаза; векторный рисунок сохраняет чёткость. Дополнительное ограничение — четверть ширины и высоты экрана.
- Отдельная настройка заметности и длительности каждого эффекта.
- Глаз по умолчанию расположен по центру: размер 100%, заметность 100%, длительность 1 секунда. Диапазоны заметности и длительности — 40–100% и 0,5–2 секунды.
- Затемнение по умолчанию: заметность 20%, длительность 0,3 секунды. Диапазоны — 2–50% и 0,1–2 секунды.
- Паузы 5, 15, 30, 60 минут или до ручного включения.
- Предпросмотр работает на паузе и сохраняет её.
- Подсказки у интервала морганий, отдыха 20–20–20 и паузы в настройках и панели строки меню: краткий текст при наведении на `i`, подробное пояснение по нажатию.
- Все настройки и пауза сохраняются между запусками; автозапуск управляется системной службой macOS.
- Отдых 20–20–20: по умолчанию каждые 20 минут появляется предложение посмотреть вдаль примерно на 6 метров. Период можно выбрать от 1 до 120 целых минут, длительность — от 5 до 300 целых секунд; по умолчанию 20 секунд. Отсчёт начинается по кнопке «Начать отдых»; предложение можно отложить на 5 минут.
- При появлении предложения звучит системный Glass, при завершении отсчёта — Tink. Звуки можно выключить; раннее завершение и прерывание отдыха беззвучны.
- Во время отдыха сигналы моргания приостанавливаются. В панели строки меню можно начать отдых сразу; автоматические предложения отдельно выключаются в настройках.
- Системное оформление SwiftUI, светлая/тёмная тема и Liquid Glass для основного действия.

## Запуск из Xcode

1. Скачайте исходники репозитория или клонируйте его.
2. Откройте `MataSehat.xcodeproj` в Xcode 26.5 и выберите общую схему **MataSehat**.
3. Выберите свой Mac как устройство запуска и нажмите **Run** (⌘R).

При первом запуске открываются настройки. После закрытия окна управление остаётся под значком глаза в строке меню. Команда «Выход» завершает приложение.

## Разработка

Внешние зависимости и база данных не нужны. SwiftUI отвечает за управление и настройки, AppKit — за прозрачное окно эффекта, ServiceManagement — за запуск при входе. Настройки хранятся в UserDefaults. Логика времени отделена от системных интеграций; unit-тесты используют Swift Testing, UI-тесты — XCTest.

После отдыха, продолжения общей паузы и возвращения из сна начинается новый цикл выбранной длительности. Изменение интервала морганий не отодвигает отдых; изменение периода отдыха начинает новый цикл ожидания. Изменение длительности и выключение автоматических предложений сохраняют уже начатый отсчёт; новые параметры применяются к следующему отдыху. Для отмены есть «Завершить раньше». Экран остаётся доступен, появление окна отдыха не переводит на него фокус.

Приложение находится в локальной разработке: поддерживается только текущий формат настроек (схема 2), без миграций старых форматов. При запуске с настройками прежней схемы используются дефолты; изменения в текущем формате сохраняются между перезапусками. Переключатель «Напоминать об отдыхе» в разделе «Отдых 20–20–20» отключает автоматические предложения; начать отдых вручную по-прежнему можно.

```sh
xcodebuild -project MataSehat.xcodeproj -scheme MataSehat \
  -destination 'platform=macOS,arch=arm64' \
  -derivedDataPath /private/tmp/matasehat-native-dd \
  CODE_SIGN_IDENTITY=- CODE_SIGN_STYLE=Manual \
  -parallel-testing-enabled NO \
  -only-testing:MataSehatTests \
  -skip-testing:MataSehatTests/OverlayWindowTests test

xcodebuild -project MataSehat.xcodeproj -scheme MataSehat \
  -configuration Release -destination 'platform=macOS,arch=arm64' \
  -derivedDataPath /private/tmp/matasehat-native-dd \
  CODE_SIGN_IDENTITY=- CODE_SIGN_STYLE=Manual build
```

Обычная проверка запускает тесты логики без управления экраном. `MataSehatUITests` и `OverlayWindowTests` взаимодействуют с рабочим столом или показывают реальные окна: их запускаем только для затронутых сценариев интерфейса и окон. После коммита, push или fast-forward объединения уже проверенного кода повторять UI-прогон не нужно. Правила для агента сохранены в [AGENTS.md](../AGENTS.md).

Локальная сборка использует ad-hoc подпись, не меняя ваши настройки подписи в Xcode. Собранное приложение для экспериментов: [build/MataSehat.app](../build/MataSehat.app). Исходный продукт Release-сборки: `/private/tmp/matasehat-native-dd/Build/Products/Release/MataSehat.app`. Готовая сборка распространяется через [GitHub Releases](https://github.com/Samaan98/MataSehat/releases). Для запуска без исключения в Gatekeeper нужны подпись Developer ID и notarization; текущий релиз использует ad-hoc подпись.

Запуск при входе регистрируется только через пользовательский переключатель. Отсутствие службы не блокирует попытку регистрации: после неё приложение показывает фактический статус macOS, необходимость системного разрешения или ошибку регистрации.

## Сборка для Releases

Универсальная Release-сборка для Apple Silicon и Intel:

```sh
xcodebuild -project MataSehat.xcodeproj -scheme MataSehat \
  -configuration Release -destination 'generic/platform=macOS' \
  -derivedDataPath /private/tmp/matasehat-release-v1-dd \
  ARCHS='arm64 x86_64' ONLY_ACTIVE_ARCH=NO \
  CODE_SIGN_IDENTITY=- CODE_SIGN_STYLE=Manual build
```

В Releases загружаем ZIP с `MataSehat.app` и файл SHA-256. Сборки остаются вне Git; тег релиза указывает на исходники соответствующей версии. До появления Developer ID и notarization инструкция установки должна объяснять исключение в Gatekeeper.

Результаты проверки и ограничения: [manual-verification.md](manual-verification.md).

## Платформенные ориентиры

- [Apple Human Interface Guidelines: macOS](https://developer.apple.com/design/human-interface-guidelines/designing-for-macos/)
- [Adopting Liquid Glass](https://developer.apple.com/documentation/technologyoverviews/adopting-liquid-glass)
- [NSHostingSceneRepresentation](https://developer.apple.com/documentation/swiftui/nshostingscenerepresentation): регистрация нативной сцены настроек и доступ к публичному openSettings из жизненного цикла приложения.

Камера, статистика, определение звонков и запись экрана в эту версию не входят.

Справка о моргании опирается на [AAO EyeWiki](https://eyewiki.aao.org/Computer_Vision_Syndrome_(Digital_Eye_Strain)); ориентир 15–20 раз в минуту не является индивидуальной нормой. Снижение частоты за экраном описано без фиксированного диапазона. Правило 20–20–20 сверено с [Mayo Clinic](https://www.mayoclinic.org/diseases-conditions/eyestrain/diagnosis-treatment/drc-20372403). Интервал 3–4 секунды предлагается как вариант для личного эксперимента с напоминаниями.
